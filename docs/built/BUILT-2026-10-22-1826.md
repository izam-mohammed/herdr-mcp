## In short

No code yet. The repository holds the spec for an MCP server, in Rust, that
lets Claude Code and other MCP clients see and control a running herdr
session (`features.md`), a chain of eight plans to build it (`PLAN.md`),
the herdr socket API, rmcp and Claude Code MCP docs (`docs/external/`), a
language benchmark that chose Rust (`docs/research/01-first-version.md`),
the project's chosen standards (`docs/standards.md`) and a README with a
light and dark banner. The repository is private.
