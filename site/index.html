herdr-mcp

You gave your AI agents their own terminals. Now one of them gets to be the boss.

an MCP server for herdr ~ it lets Claude Code, Codex or any other MCP client list, open, close, read, prompt and wait on everything in your herdr session. middle management, in rust, cheaper than the human kind.

Linux and macOS, x86_64 and arm64 ~ needs herdr ~ MIT

Start here

Paste this into Claude Code or Codex, running inside a herdr pane. It installs the server, registers it and checks that it works.

Install the herdr MCP server for me.

1. Run the installer from the latest release:
   curl --proto '=https' --tlsv1.2 -LsSf https://github.com/izam-mohammed/herdr-mcp/releases/latest/download/herdr-mcp-installer.sh | sh
2. Open a new shell if needed, then run `herdr-mcp --version` and tell me the version.
3. Register it: `claude mcp add herdr -- herdr-mcp` (Claude Code) or
   `codex mcp add herdr -- herdr-mcp` (Codex).
4. Tell me to restart you inside a herdr pane. After the restart, call
   herdr_whoami and herdr_tab_list and show me what you see.

No sudo, no Rust toolchain. If a step fails, show me the exact error and stop.

Started anywhere but a herdr pane, the server is read-only: it can look and not touch. Prefer to do it by hand? The same steps are in the docs.

What it can do

  • workspaces ~ list, create, focus, rename, move and close them
  • tabs ~ the same, one level down
  • panes ~ read, split, run a command and wait for it, type, resize, close
  • agents ~ see each one's state (idle, working, blocked, done), read it, prompt it, wait on it
  • events ~ what changed since it last looked, or wait until any agent goes blocked
  • worktrees, layouts and toasts ~ open a git worktree as a workspace, save and rebuild a tab, show a notification

63 tools by default (26 more in an admin group that is off), 7 resources and 3 prompts, each with a page in the docs.

What it won't do

Read-only outside herdr. It never prompts, types into or closes its own pane, and it treats everything a pane prints as data, never instructions. Stopping or reconfiguring herdr itself needs the admin group, which is off until you turn it on.
