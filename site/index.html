herdr-mcp

You gave your AI agents their own terminals. Now one of them gets to be the boss.

an MCP server for herdr ~ it lets Claude Code, Codex or any other MCP client list, open, close, read, prompt and wait on everything in your herdr session. middle management, in rust, cheaper than the human kind.

Latest release

Linux and macOS, x86_64 and arm64 ~ needs herdr ~ MIT

Install

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/izam-mohammed/herdr-mcp/releases/latest/download/herdr-mcp-installer.sh | sh
herdr-mcp --version
claude mcp add herdr -- herdr-mcp     # Claude Code
codex mcp add herdr -- herdr-mcp      # Codex

The repository is private today, so the one-liner only works once it is public. Until then, with access, download a release archive with gh release download; the README has the steps. Then start your agent inside a herdr pane: started anywhere else, it is read-only.

What it can do

  • workspaces ~ list, create, focus, rename, move and close them
  • tabs ~ the same, one level down
  • panes ~ read, split, run a command and wait for it, type, resize, close
  • agents ~ see each one's state (idle, working, blocked, done), read it, prompt it, wait on it
  • events ~ what changed since it last looked, or wait until any agent goes blocked
  • worktrees, layouts and toasts ~ open a git worktree as a workspace, save and rebuild a tab, show a notification

57 tools, 7 resources and 3 prompts in all, each with a page in the docs.

What it won't do

Read-only outside herdr. It never prompts, types into or closes its own pane, and it treats everything a pane prints as data, never instructions. It cannot stop or reconfigure herdr itself.
